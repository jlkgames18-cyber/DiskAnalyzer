# Disk Space Analyzer 📊

محلل مساحة القرص - تطبيق ذكي وبسيط مبني بلغة بايثون واجهة PyQt6 لفحص القرص وتحديد الملفات الكبيرة والمكررة لإخلاء المساحة.

## ✨ المميزات (Features)
- **واجهة مستخدم احترافية:** تصميم شريطي كلاسيكي داكن (Classic Black Ribbon UI) مريح للعين.
- **ثنائي اللغة:** يدعم اللغتين العربية والإنجليزية بالكامل (Bilingual AR/EN).
- **فحص سريع وصاروخي:** يعتمد على `os.scandir` للحصول على أعلى سرعة فحص ممكنة.
- **أدوات ذكية:** 
  - كاش محلي باستخدام قاعدة بيانات `SQLite` لتسريع عمليات الفحص اللاحقة.
  - مكتشف الملفات المكررة بدقة باستخدام شفرات `MD5`.
  - التعرف التلقائي على المجلدات الفارغة، الملفات المؤقتة، والملفات القديمة.
  - إمكانية حذف الملفات أو نقلها إلى سلة المهملات بأمان عبر `send2trash`.

## 🛠️ التثبيت والتشغيل (Installation)

لإعداد المشروع وتشغيله على جهازك، قم بتنفيذ الأوامر التالية:

```bash
# 1. استنساخ المستودع
git clone https://github.com](https://github.com/jlkgames18-cyber/DiskAnalyzer

# 2. الانتقال إلى مجلد المشروع
cd Disk-Space-Analyzer

# 3. تثبيت المكتبات المطلوبة
pip install -r requirements.txt

# 4. تشغيل التطبيق
python main.py
```
